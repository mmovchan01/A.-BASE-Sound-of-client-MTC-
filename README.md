# A. BASE: Голос клиента (MTC)

Решение классифицирует эмбеддинги коротких аудиореплик на четыре класса: `angry`, `neutral`, `positive`, `sad`.

## Модель

Используется компактный полносвязный MLP: `2048 -> 512 -> 128 -> 4` (параметров около 1,1 млн). Перед обучением признаки стандартизируются по статистикам обучающей части. Обучение выполняется с весами классов, вычисленными по частотам меток, оптимизатором Adam. Число эпох и выбор лучшего checkpoint определяются по macro-F1 на стратифицированной отложенной выборке. Для финальных предсказаний сохраняются небольшие смещения логитов классов, подобранные на этой же валидационной выборке под macro-F1.

Модель работает на CPU; GPU не требуется. Все случайные состояния задаются одним seed. Если seed не передан явно, `train.py` выбирает его случайно, печатает и сохраняет в файле модели. `predict.py` использует этот seed в имени submission.

## Запуск

```bash
python -m pip install -r requirements.txt

# Если train.npz хранится в Git LFS:
git lfs pull

# Обучение со случайным seed (он будет напечатан и сохранён в модели).
python train.py --train-path train.npz

# Предсказание; по умолчанию создаётся submission_seed_<seed из модели>.npz
python predict.py --input public_test.npz --model artifacts/emotion_mlp.joblib
```

Для точного повторения уже выполненного обучения передайте сохранённое значение явно: `python train.py --train-path train.npz --seed <SEED>`. Seed можно также задать при первом запуске.

Параметры обучения можно менять через аргументы командной строки; например, `--max-epochs 40`, `--patience 7` или `--hidden-layers 512,128`. После запуска обучения в терминале печатаются macro-F1 на validation, а checkpoint сохраняется в `artifacts/emotion_mlp.joblib`.

Submission — NPZ-файл с двумя полями:

- `embeddings` — исходные эмбеддинги тестовой выборки;
- `targets` — предсказанные строковые метки.

`predict.py` не запускает обучение и не читает метки из `sample_submission.npz`.

## Данные

`train.npz` должен содержать поля `embeddings` (матрица `N x D`) и `targets` (строковые метки). Открытый тест читается из `public_test.npz`, поле `embeddings`. В текущем checkout `train.npz` может быть Git LFS pointer-файлом; сначала нужно получить сам объект командой `git lfs pull` или скачать обучающую выборку из источника соревнования.
